# BeePlus

Cursor plugin that connects the agent to a BeePlus workspace over MCP.

After you connect and authorize, Cursor can use the teams, panels, activities, tasks, phases, and sprint cycle that your BeePlus user already has access to.

## Requirements

- A BeePlus account with MCP enabled (Admin, then Integration).
- Cursor 3.15 or newer.

## Connect

1. Install this plugin from the Cursor Marketplace.
2. In MCP, choose **Connect** on BeePlus.
3. Sign in at https://app.beeplus.io and allow access.

The server address in this repository is https://app.beeplus.io/mcp.
